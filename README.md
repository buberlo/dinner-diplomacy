# Dinner Diplomacy

> Plan meals like border wars, then serve a peace treaty.

A web app turns a household’s changing food restrictions into a living map where each diet controls territory. When someone adds gluten-free, vegan, or “no more fish,” adjacent territories redraw and trigger tiny negotiation events. The final menu is exported as a signed peace treaty with who owes what to the table.

## Features
- Territory map renders each household member’s diet as a colored region
- Diet changes trigger border redraws and generate negotiation prompts
- Menu items are placed on shared land and marked as acceptable, borderline, or hostile
- One-click export produces a printable treaty with meal plan and apologies

## Stack
- React
- D3.js
- Zustand
- SQLite

## Getting started
```
npm install && npm run dev
```
